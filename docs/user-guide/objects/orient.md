# Orient

**Orient** places objects on the terrain and **tilts them to follow the slope**. Use it for things that
should lie flat to the ground: paving, decking, floor plates, sleepers, rocks that sit on a bank.

## Settings

| Setting | Meaning |
|---|---|
| **Sources** | The Rhino objects and layers to place |
| **Rotate Min / Max** | Random rotation range (degrees) |
| **Scale Min / Max** | Random uniform scale range |
| **Seed** | Stable random seed for this card |
| **Z Offset** | Lift or sink along each object's up axis |

The objects stay on their original layers. The card moves and tilts your source objects, and re-seats them
when the terrain beneath them changes.
