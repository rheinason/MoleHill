# Spot Heights (Points)

Places **elevation labels at points** projected onto the terrain. Use it for spot levels at corners,
inverts and key positions.

## Settings

| Setting | Meaning |
|---|---|
| **Sources** | Point objects and curve edit points projected to the terrain for labels |
| [**Block settings**](README.md#block-annotation-settings) | Block, Decimals, Prefix, Suffix, Block Scale, Color |

## Results

- **Sources / Labels**: sources found and labels generated.
- **Min / Max**: projected terrain elevations.

## Tips

Edit points of a curve work as sources too. Select a curve's control points to label each vertex.
