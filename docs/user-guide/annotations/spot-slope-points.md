# Spot Slope (Points)

Places **slope labels with arrows at points**, reading the local terrain slope under each point.

## Settings

| Setting | Meaning |
|---|---|
| **Sources** | Point objects and curve edit points projected to the terrain before the local slope is sampled |
| **Units** | Show slopes as percent, promille, ratio or degrees |
| **Flip Arrow** | Rotate slope arrows 180° |
| [**Block settings**](README.md#block-annotation-settings) | Block, Decimals, Prefix, Suffix, Block Scale, Color |

## Results

- **Points / Labels**: points found and labels generated.
- **Min / Avg / Max**: local slope values.
