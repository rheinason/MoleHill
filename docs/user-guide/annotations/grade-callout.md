# Grade Callout

Labels the **grade between the two ends of a line**, as a ratio (1:n) and a percentage. Use it for
drainage runs, pipe gradients and ramps.

## Settings

| Setting | Meaning |
|---|---|
| **Sources** | Lines whose two endpoints define the grade. Each line produces one callout |
| **Decimals** | Decimal places on the percentage part |
| **Prefix** | Text placed before the callout |
| **Suffix** | Text placed after the callout |
| **Color** | Colour for the callout. Clear to follow the layer |

## Results

- **Lines / Callouts**: lines found and callouts generated.
- **Min / Avg / Max %**: grade percentages computed.
