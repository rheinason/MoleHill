# Spot Heights (Curve)

Places **elevation labels at regular stations along curves**, reading the height from the terrain. Use it
for road centrelines, kerbs, swale inverts and wall tops.

## Settings

| Setting | Meaning |
|---|---|
| **Sources** | Curve objects or layers sampled along the terrain at regular stations |
| **Interval** | Distance along each curve between stations |
| [**Block settings**](README.md#block-annotation-settings) | Block, Decimals (*Number of decimal places shown*), Prefix, Suffix, Block Scale, Color |

## Results

- **Curves / Labels**: curves found and labels generated.
- **Min / Max**: lowest and highest elevation sampled.
