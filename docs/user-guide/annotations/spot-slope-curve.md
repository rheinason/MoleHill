# Spot Slope (Curve)

Places **slope labels with arrows along curves**, showing the terrain-projected grade of each span.

## Settings

| Setting | Meaning |
|---|---|
| **Sources** | Curve objects or layers projected onto the terrain before grade is sampled |
| **Interval** | Distance along each curve between sampled slope spans |
| **Units** | Show slopes as percent, promille, ratio or degrees |
| **Flip Arrow** | Rotate slope arrows 180° to match other office conventions |
| [**Block settings**](README.md#block-annotation-settings) | Block, Decimals, Prefix, Suffix, Block Scale, Color |

## Results

- **Curves / Labels**: curves found and labels generated.
- **Min / Avg / Max**: slope values sampled along the curves.
